TRENDORA WEBSITE RECREATION
============================

Files:
- index.html       Main editorial landing page shell (links into the archive)
- trends.html      Trends archive page
- styles.css       Responsive styling
- script.js        Category filters, search, mobile navigation and newsletter interaction

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. For the archive, open trends.html?category=trends (or use the category links).

NOTES
- This is a front-end recreation based on the publicly visible TRENDORA website.
- The original Lovable project's private source code, backend, database, and original image assets are not included.
- Editorial images are loaded from Unsplash URLs and therefore require an internet connection.
- Newsletter submission and article links are demo interactions; no email is sent and no backend is connected.
